### Описание

- Сайт создан для всех любителей атмосферного **хоррора** и **экстрима** в мире Minecraft. Здесь собрана подборка проверенных, качественных модов, которые превратят привычный игровой процесс в пугающее приключение: от зомби-апокалипсисов и проклятых биомов до жутких мобов, зловещих локаций и улучшенной физики страха. На сайте вы найдете описания модов, системные требования, ссылки на загрузку и удобные фильтры для поиска контента по версии Minecraft и жанру хоррора.

### Функциональность

- Адаптивный дизайн, корректно отображающийся на устройствах с любым разрешением (от смартфонов до десктопов)
Переключатель темы: светлая тема для комфортного просмотра днем и темная, снижающая нагрузку на глаза и подчеркивающая атмосферу хоррора, для ночного использования (с сохранением выбранной темы в локальном хранилище браузера)
Интуитивно понятная навигация между страницами: главная с подборкой модов, страница информации о каждом моде, фильтры по версии Minecraft и жанру контента
Умный поиск по названию мода, описанию и тегам, позволяющий быстро найти нужный хоррор-мод
Легкие JS-эффекты: параллакс при прокрутке главной страницы, плавное раскрытие описаний модов, анимация при наведении на карточки, плавный переход между страницами для комфортного пользования
