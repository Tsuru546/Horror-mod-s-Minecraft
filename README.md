### Описание

- Сайт создан для всех любителей атмосферного **хоррора** и **экстрима** в мире Minecraft. Здесь собрана подборка проверенных, качественных модов, которые превратят привычный игровой процесс в пугающее приключение: от зомби-апокалипсисов и проклятых биомов до жутких мобов, зловещих локаций и улучшенной физики страха. На сайте вы найдете описания модов, системные требования, ссылки на загрузку и удобные фильтры для поиска контента по версии Minecraft и жанру хоррора.

### Функциональность

- Адаптивный дизайн, корректно отображающийся на устройствах с любым разрешением (от смартфонов до десктопов)
Переключатель темы: светлая тема для комфортного просмотра днем и темная, снижающая нагрузку на глаза и подчеркивающая атмосферу хоррора, для ночного использования (с сохранением выбранной темы в локальном хранилище браузера)
Интуитивно понятная навигация между страницами: главная с подборкой модов, страница информации о каждом моде, фильтры по версии Minecraft и жанру контента
Умный поиск по названию мода, описанию и тегам, позволяющий быстро найти нужный хоррор-мод
Легкие JS-эффекты: параллакс при прокрутке главной страницы, плавное раскрытие описаний модов, анимация при наведении на карточки, плавный переход между страницами для комфортного пользования

├── data/                     # Исходные данные
│   ├── mods/                 # JSON/YAML файлы с описаниями каждого мода
│   └── games.json            # Справочник поддерживаемых игр
├── scripts/                  # Утилиты для валидации и сборки

🛠 Как добавить свой мод в базу

Мы приветствуем контрибьюторов! Чтобы добавить новую модификацию, следуйте этому алгоритму (удобнее всего делать через интерфейс VS Code):

Создайте новую ветку: git checkout -b feat/add-[название-мода].
Добавьте данные: Создайте файл в папке data/mods/ (например, darkdream_anomaly.json). В VS Code для этого идеально подойдет расширение JSON Schema Store — оно будет подсказывать поля прямо во время набора кода.
Добавьте скриншоты: Поместите 2-3 изображения в assets/screenshots/. Назовите их по шаблону: [мод]_[игра]_[1].jpg.
Проверьте ссылки: Запустите python scripts/validate_links.py.
Создайте Pull Request. В описании укажите версию игры, на которой проводилось тестирование.

Рекомендации по редактированию Markdown в VS Code:

Используйте сочетание клавиш Ctrl + Shift + M (или Cmd + Shift + M на Mac) для быстрого предпросмотра Markdown.
Включите форматирование при сохранении в settings.json: "editor.formatOnSave": true.
Для работы с таблицами можно использовать расширение Markdown Table Prettify, чтобы автоматически выравнивать столбцы.
📦 Как пользоваться сборником
Перейдите в раздел «Каталог» на сайте.
Используйте фильтры по игре, типу хоррора и сложности.
Нажмите на карточку мода, чтобы открыть подробное описание.
Внимательно прочитайте раздел «Установка» и «Известные проблемы».
Скачайте архив и установите мод согласно инструкции. Совет: для большинства игр VS Code отлично подходит как редактор конфигурационных файлов (.ini, .cfg, .toml). Просто нажмите на файл правой кнопкой мыши и выберите «Open with...» -> VS Code.
Обязательно сделайте чистую копию профиля игры или копию папки savegames перед установкой!
🐛 Известные проблемы
Моды для S.T.A.L.K.E.R. на версиях движка 1.5.0 и ниже могут вызывать утечки памяти при включенном DX11 Enhanced.
Пакеты текстур в 4K для Minecraft требуют минимум 6 ГБ видеопамяти, иначе возможны статтеры.
Half-Life 2 моды на новых версиях Windows 11 могут требовать принудительного запуска в режиме совместимости с Windows 7.
